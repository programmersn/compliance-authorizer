# examples/ — committed, byte-reproducible demo evidence

This folder holds a single, self-contained worked example: one signed
**deny** decision and everything an outsider needs to verify and reproduce it
**offline, with zero trust in any server**. Every file is committed and
deterministic, so `npm run verify:fixture` and `npm run replay` behave
identically on any machine.

> **UNCERTIFIED.** This is a **synthetic demo rule pack** — **not a fatwa / not
> certified / not production advice**. The scenario label ("casino-hotel") is a
> generic synthetic placeholder; there is no real merchant, customer, or PII
> anywhere here. The evidence is **committee-reviewable demo evidence**, not a
> certified ruling. A certified version *would* additionally carry a scholar's
> `did:key` and a detached signature over the rule pack's hash; this demo
> deliberately carries an UNCERTIFIED scholar-signature slot instead.

## What each file is

| File | What it is |
|---|---|
| `issuer.demo.jwk.json` | **THROWAWAY demo PRIVATE key.** A committed Ed25519 private JWK (see the warning below). Signs the demo evidence so the example is byte-reproducible. |
| `jwks.json` | The **public** JWKS (RFC 7517) for that key — the verifying key, no private `d`. This is what `GET /.well-known/jwks.json` serves. |
| `pack.json` | A verbatim copy of `rule-packs/shariah/0.1.1.json` so you can re-hash it and match the envelope's `rule_pack_hash`. |
| `casino-hotel.evidence.jws` | The signed **deny** evidence artifact (JWS-compact). The thing you verify and replay. |

### ⚠️ `issuer.demo.jwk.json` is a throwaway demo key — committed on purpose

This private key is **intentionally committed**. It exists ONLY to make this one
example byte-reproducible. It signs **nothing but synthetic UNCERTIFIED demo
evidence**. It is **not** a production key, has **no** value, and **must never**
be reused for anything real. Production keystores live under `.keys/` (gitignored)
and are never committed.

## Verify it (authenticity — offline, zero server trust)

```sh
npm run verify:fixture
# ≡ node verifier/verify.mjs \
#     --evidence examples/casino-hotel.evidence.jws \
#     --jwks examples/jwks.json \
#     --pack examples/pack.json
```

Expected: every check `PASS`, `RESULT: PASS — decision "deny"`, exit `0`. The
verifier re-checks the Ed25519 signature, that `kid` equals the key's RFC 7638
thumbprint, the RFC 8785 canonical form of the payload, `intent_hash`, and
`rule_pack_hash`. It uses **node built-ins only** — no dependency on this
service's source.

## Replay it (reproducibility — re-derive the decision)

```sh
npm run replay
# ≡ node --experimental-strip-types --no-warnings scripts/replay.ts \
#     --evidence examples/casino-hotel.evidence.jws \
#     --pack examples/pack.json
```

Expected: `RESULT: REPRODUCED — re-evaluation yields decision "deny"`, exit `0`.
Replay re-runs the **pure, deterministic** evaluator on the cited
`payment_intent` + pack and confirms the SAME decision the envelope records.

A bare `replay` checks reproducibility **only** — its `exit 0` is **not** an
authenticity verdict. To fold both into one exit code, add `--jwks` (here:
`npm run replay:verified`), which also runs the offline verifier and requires
**reproduced AND authentic** for `exit 0`.

**Authenticity and reproducibility are different properties.** `verify.mjs`
proves the bytes are authentic and intact; it deliberately does **not** re-run
the evaluator. `replay` proves the cited decision re-derives. A fuller
walkthrough — including how a tampered-then-re-signed artifact can be authentic
yet *not* reproduce — is in [`../REPRODUCIBILITY.md`](../REPRODUCIBILITY.md).

## Regenerate (idempotent)

```sh
npm run build:example
```

Rewrites `jwks.json`, `pack.json`, and `casino-hotel.evidence.jws` with
identical bytes every run. It **imports** the committed demo key (never
generates one) — that fixed key, plus a fixed clock/UUID and the RFC 8785
canonical envelope, is why the deterministic Ed25519 signature is byte-stable.
`test/w2-examples.test.ts` asserts the regenerated bytes equal the committed
artifact exactly.
