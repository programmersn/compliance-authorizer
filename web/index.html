Decision states

Escalating visual weight, icon + word always — never color alone.

ALLOW
Permitted. Light, green check. The one semantic use of green.
REVIEW
Halt, escalate to your committee. Amber, not grey — a discipline, not a failure.
DENY
Prohibited. Heavy inked block + slash. A valid result, not an error.
SYSTEM ERROR
Not a decision. Dashed panel, never a certificate. Unsigned 4xx — no envelope exists.

For developers & bank validators

One command to a signed decision. Reproduce any envelope offline, trusting nothing on our server. MIT-licensed, with a written machine contract — agent-native by construction.

  • A decision is always HTTP 200 — a DENY is 200; read body.decision, never the status code.
  • Malformed input is 4xx problem+json — an integration failure, never a signed decision.
MIT on GitHub ↗ Verify offline (REPRODUCIBILITY.md) ↗ Machine contract (always-200) ↗ Issuer keys (jwks.json) Rule pack (canonical bytes)
